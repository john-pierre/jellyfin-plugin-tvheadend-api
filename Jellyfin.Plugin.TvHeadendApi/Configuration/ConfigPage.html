Relay Service

The relay proxies images and streams through Jellyfin so TVHeadend credentials and internal URLs stay hidden from clients.

Relay Token Security

Protects public relay endpoints with plugin-issued, scoped, short-lived tokens. Required because Jellyfin/FFmpeg does not reliably send auth headers to plugin endpoints.

When enabled, public relay endpoints require a plugin-issued token. Disable only for debugging. Strongly recommended: enabled.
⚠️ Relay token security is disabled — public relay endpoints are unprotected.

Stream Tokens

Image Tokens

Maximum uses for image relay tokens. Set to 0 for unlimited (recommended for images).

Streaming Profile Rules

Hierarchical rules controlling which TVHeadend streaming profile is used per channel, client, or user.

Resolution hierarchy — first match wins:
  1. Channel override — per individual channel
  2. Channel group override — per category (Sports, News, Kids…)
  3. Client / device rule — per app or device (Swiftfin, Web, Android TV…)
  4. User rule — per Jellyfin user
  5. Global default — configured below
  6. Legacy fallback — the Streaming Profile selected above
  7. Safe fallback — hardcoded "pass"

Global Defaults

Profile name for the global default. Leave empty to fall back to the legacy Streaming Profile above.

Last-resort profile when a resolved profile name turns out to be empty or invalid.
Log detailed resolution trace for every playback request. Useful for debugging rules.

Play Method

Lets the client play the stream as-is. Fastest option — keep enabled.
Allows Jellyfin to change the container without re-encoding. Fast fallback when Direct Play is not possible.

Probing & Cache

Jellyfin analyses stream metadata before playback. Keep enabled when using a transcode profile with pre-created cache files — the probe resolves instantly.
Technical details… Without cached metadata, Jellyfin adds a 3 s probe delay for live streams. With matching cache files, the probe resolves instantly.
Pre-creates mediainfo cache files based on the selected streaming profile, making even the first tune fast by skipping FFmpeg probing.
Compares existing cache files with the active streaming profile. Outdated files are deleted and optionally replaced when pre-create is also enabled.

Stream Tuning

Ignore Decode Time Stamps. Can fix playback glitches with some MPEG-TS streams.
Allows Jellyfin metadata plugins to enrich EPG entries using provider hints parsed from TvHeadend URIs.
Stream buffer in milliseconds. 0 = Jellyfin default. Lower values reduce latency.
Time FFmpeg spends analysing the stream before playback. Default: 200 ms. Set 0 for automatic fallback.
Technical details… When Stream Probing is on, Jellyfin overrides this to 3000 ms for live streams. This value only applies when probing is off.

Fast Channel Switching Guide (< 3 seconds)

Goal: Switch channels in under 3 seconds — even on the first tune.

1
Create the "jellyfin" transcode profile
Click "Create jellyfin Profile" above. This outputs every channel as H.264 + AAC — a format Jellyfin can Direct Play.
Manual alternative…In TvHeadend: Configuration → Stream → Stream Profiles → Add profile-transcode. Set Container = MP4, Video = libx264, Audio = AAC.
2
Select the profile
In the Streaming section, set Streaming Profile to jellyfin.
3
Enable fast playback settings
In Playback Behaviour, enable: Direct Play, Direct Stream, Stream Probing, and Pre-create Probe Cache Files.
How it works

TvHeadend transcodes every channel to a consistent format. The plugin pre-creates Jellyfin's mediainfo cache files with matching metadata. When you switch channels, Jellyfin finds the cache instantly, skips FFmpeg probing, and starts Direct Play.
