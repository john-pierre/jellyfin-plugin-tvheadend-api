Status & Health Check

Test your TVHeadend connection and review the current configuration at a glance.

Connection

How the plugin reaches your TVHeadend server.

Hostname or IP address of your TVHeadend server.
The port TVHeadend listens on for HTTP API requests. Default: 9981.
Enable if your TVHeadend server uses HTTPS (SSL/TLS).
Accept self-signed or invalid SSL certificates. Not recommended for production.
Only needed if TVHeadend sits behind a reverse proxy under a sub-path (e.g. /tvh/). Default: /.

Authentication

Credentials used to connect to TVHeadend.

Enable only if TVHeadend permits unauthenticated connections. When checked, username & password are ignored.
TVHeadend username for HTTP Basic Auth.
TVHeadend password for HTTP Basic Auth.
Optional persistent access token. Appended as ?auth=… to image and icon URLs. Leave empty if unused.

Streaming

Controls how live TV streams are requested from TVHeadend.

Name of the TVHeadend stream profile to use for live TV. pass delivers the original broadcast stream without transcoding. If you want fast channel switching, create a dedicated transcoding profile in TVHeadend (e.g. webtv-h264-aac-mpegts) and enter its name here.
Fallback maximum bitrate in bits per second when no stream-level bitrate is known. Default: 30 000 000 (≈ 30 Mbps).
Treat the stream as never-ending (correct for live TV). Should almost always be enabled.

Playback Behaviour

Fine-tune how Jellyfin handles the incoming stream. If you are unsure, leave the defaults.

Allow the client to play the stream as-is, without any server-side processing. Best for performance.
Allow Jellyfin to change the container format without re-encoding the video/audio.
Allow Jellyfin to transcode the stream on-the-fly if a client cannot play the original format. Increases server load.
Let Jellyfin analyse (probe) the stream to detect codecs and format before playback. Disabling this reduces channel-switch time but requires that the format is known in advance (see "Fast Channel Switching" below).
Ignore Decode Time Stamps. Can fix playback glitches with some MPEG-TS streams.
Stream buffer in milliseconds. 0 = Jellyfin default. Lower values reduce latency but may cause stuttering on slow connections.
Time FFmpeg spends analyzing the stream before playback starts. 0 = Jellyfin default. Overridden to 0 when Fast Channel Switching is active.

Fast Channel Switching

Speed up channel changes dramatically by telling Jellyfin exactly what format the stream uses. This eliminates the need for probing / analysis before playback can start.

Prerequisite: You must configure a TVHeadend streaming profile that transcodes every channel into the same fixed output format (e.g. H.264 + AAC in MPEG-TS). Enter that profile name in "Streaming Profile" above, then describe its output here.

When enabled, stream probing is skipped and the format hints below are sent to Jellyfin instead. Only enable this when every channel delivers the same format.

Container

The container format output by TVHeadend. Common values: mpegts, matroska, mp4.

Video

Video codec name as FFmpeg knows it. Common: h264, hevc, mpeg2video. Leave empty to omit the video hint.
Horizontal resolution in pixels. 0 = unspecified.
Vertical resolution in pixels. 0 = unspecified.
Frames per second. PAL regions typically use 25, NTSC use 30. 0 = unspecified.
Video bitrate in bits per second. 0 = unknown / let Jellyfin estimate.
Check if the TVHeadend profile outputs interlaced video. Transcoded streams are usually progressive (unchecked).

Audio

Audio codec name. Common: aac, ac3, eac3, mp2. Leave empty to omit the audio hint.
Number of audio channels. 1 = mono, 2 = stereo, 6 = 5.1 surround. 0 = unspecified.
Audio sample rate in Hz. Most streams use 48000. 0 = unspecified.
Audio bitrate in bits per second. 0 = unknown / let Jellyfin estimate.

Recording (DVR)

Settings for TVHeadend-managed recordings. Disable if you want Jellyfin to handle DVR on its own.

When enabled, recording timers and series timers are managed by TVHeadend. Disable to let Jellyfin record from the live stream instead.
Recording priority (lower = higher priority). Default: 5.
Seconds to start recording before the scheduled programme time.
Seconds to continue recording after the scheduled end time.
Name of the TVHeadend DVR configuration profile. Must exist in your TVHeadend setup.
