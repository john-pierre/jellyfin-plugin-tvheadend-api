Fast Channel Switching Guide (< 3 seconds)

Goal: Switch channels in under 3 seconds — even on the first tune.

1
Create the "jellyfin" transcode profile
Click "Create jellyfin Profile" in the banner above. This outputs every channel as H.264 + AAC — a format Jellyfin can Direct Play.
2
Select the profile
In the Streaming section, set the Default profile to jellyfin.
3
Enable fast playback settings
In Playback Behaviour, enable: Direct Play, Direct Stream, Stream Probing, and Pre-create Probe Cache Files.
How it works

TvHeadend transcodes every channel to a consistent format. The plugin pre-creates Jellyfin's mediainfo cache files with matching metadata. When you switch channels, Jellyfin finds the cache instantly, skips FFmpeg probing, and starts Direct Play.

Authentication

Credentials used to authenticate with TvHeadend.

Enable only if TvHeadend permits unauthenticated connections. Username and password are ignored when checked.
TvHeadend username for HTTP Basic Auth. Required when anonymous access is disabled.
TvHeadend password for HTTP Basic Auth. Required when anonymous access is disabled.
Persistent access token appended as ?auth=… to stream and image URLs, allowing clients to play channels without additional authentication. Allowed format: letters and digits only (A-Z, a-z, 0-9).

Relay Service

The relay proxies images and streams through Jellyfin so TVHeadend credentials and internal URLs stay hidden from clients.

When enabled, all image and stream URLs point to Jellyfin's relay endpoints instead of TVHeadend directly. Recommended for security.
Override the Jellyfin base URL used in relay URLs. Leave empty to use the auto-detected host.

Relay Token Security

Protects public relay endpoints with plugin-issued, scoped, short-lived tokens. Required because Jellyfin/FFmpeg does not reliably send auth headers to plugin endpoints.

When enabled, public relay endpoints require a plugin-issued token. Disable only for debugging. Strongly recommended: enabled.
⚠️ Relay token security is disabled — public relay endpoints are unprotected.

Stream Tokens

Controls how long a token may be used to start a new relay request. Active streams are not interrupted after expiry. Minimum: 10 seconds.
Allows probing, retries, and the final playback request. A value of 5 is recommended for Jellyfin/FFmpeg compatibility. Set to 0 for unlimited.

Image Tokens

0 = never expire (recommended). Jellyfin caches image URLs (with the embedded token) for a long time; a non-zero TTL can make channel logos and EPG images return 401/410 once the token expires. Only set a positive value if you have a specific security requirement.
Maximum uses for image relay tokens. Set to 0 for unlimited (recommended for images).

Advanced

Allow the same token to be used multiple times within its TTL and max-uses limits.
A stream token for channel A cannot be used for channel B. An image token cannot access a stream endpoint.
How often expired and revoked tokens are cleaned up from the database. Minimum: 1 minute.
Tolerance for minor clock differences between token issuance and validation.

Streaming

Controls how live TV streams are requested from TvHeadend and which profile is used per channel, client, or user.

Relay proxies the stream through Jellyfin so TVHeadend credentials/URLs are never exposed to clients; the Jellyfin host is auto-derived from the client request (the host override is only needed for unusual reverse-proxy setups). Direct to TVHeadend points clients straight at TVHeadend with an auth token — fastest and needs no reachable Jellyfin host, but exposes the TVHeadend host and token to clients. Direct mode requires a configured Auth Token (or anonymous access); otherwise it falls back to relay.
Fallback maximum bitrate in bits per second when no stream-level bitrate is known. Default: 3,000,000 (~3 Mbps).
Treat the stream as never-ending. Should almost always be enabled for live TV.

Playback Behaviour

Controls how Jellyfin handles the incoming stream. Settings that affect channel switching speed are highlighted.

Play Method

Lets the client play the stream as-is. Fastest option — keep enabled.
Allows Jellyfin to change the container without re-encoding. Fast fallback when Direct Play is not possible.
Allows full transcoding as a last resort. Adds ~3 s extra delay.

Probing & Cache

Jellyfin analyses stream metadata before playback. Keep enabled when using a transcode profile with pre-created cache files — the probe resolves instantly.
Technical details… Without cached metadata, Jellyfin adds a 3 s probe delay for live streams. With matching cache files, the probe resolves instantly.
Deprecated — cache is now always active when Stream Probing is enabled.
Deprecated — cache validation is now always active when Stream Probing is enabled.

Stream Tuning

Ignore Decode Time Stamps. Can fix playback glitches with some MPEG-TS streams.
Allows Jellyfin metadata plugins to enrich EPG entries using provider hints parsed from TvHeadend URIs.
Stream buffer in milliseconds. 0 = Jellyfin default. Lower values reduce latency.
Time FFmpeg spends analysing the stream before playback. Default: 200 ms. Set 0 for automatic fallback.
Technical details… When Stream Probing is on, Jellyfin overrides this to 3000 ms for live streams. This value only applies when probing is off.
