Playback Behaviour

Fine-tune how Jellyfin handles the incoming stream. If you are unsure, leave the defaults.

Allow the client to play the stream as-is, without any server-side processing. Best for performance.
Allow Jellyfin to change the container format without re-encoding the video/audio.
Allow Jellyfin to transcode the stream on-the-fly if a client cannot play the original format. Increases server load.
Let Jellyfin analyse (probe) the stream with FFmpeg to detect codecs and format before playback. Recommended: OFF. The plugin queries TVHeadend for stream details automatically, which is faster and avoids probing entirely.
⚠️ Jellyfin core behaviour when probing is ON:
  • Jellyfin always waits at least 3 seconds before probing (Math.Max(3000, AnalyzeDurationMs)).
  • Jellyfin overrides the AnalyzeDuration to 3000 ms for all live streams, regardless of what this plugin sets.
  • Jellyfin caches probe results on disk (under <data>/cache/mediainfo/). The first probe takes 3+ seconds; subsequent opens of the same channel use the cache and complete in milliseconds.
  • The cache key is derived from the stream's LiveStreamId. It persists until Jellyfin clears its cache.
Ignore Decode Time Stamps. Can fix playback glitches with some MPEG-TS streams.
Stream buffer in milliseconds. 0 = Jellyfin default. Lower values reduce latency but may cause stuttering on slow connections.
When enabled, the plugin reads Jellyfin's mediainfo probe cache files (<data>/cache/mediainfo/*.json) and uses the detailed stream data from previous FFmpeg probes (ColorRange, ColorSpace, Profile, Level, PixelFormat, RealFrameRate, DisplayTitle, etc.) instead of the synthetic streams built from TVHeadend's basic service API.
Requires at least one prior probe run per channel to populate the cache. You can trigger this by temporarily enabling Stream Probing, opening each channel once, then disabling probing again.
Time FFmpeg spends analysing the stream before playback starts, in milliseconds. 0 = automatic: the plugin defaults to 200 ms when TVHeadend stream details are available. If no stream details are found and probing is active, Jellyfin's global FFmpeg setting is used as fallback.
⚠️ Important: When Stream Probing is enabled, Jellyfin's core always overrides this value to 3000 ms for live streams. This plugin's value only takes effect reliably when probing is OFF and the plugin provides stream details from TVHeadend.
Note: -probesize is controlled by Jellyfin's global FFmpeg settings (Dashboard → Playback → FFmpeg) and cannot be changed from this plugin.
